# 3. Deploy with GitHub Actions

After [OIDC and API permissions](configure-azure-oidc-for-github-actions.md) are ready, push to `main` or run [.github/workflows/app-service.yml](../.github/workflows/app-service.yml) from `main`. PRs perform build/unit/host/setup and explicit stub-browser validation only: they do not mutate Azure. SWA PR previews and PR-close cleanup are removed; this B1 baseline does not provide replacement preview environments.

Deployment validates required configuration, logs in with federation, provisions Bicep incrementally, stamps public client telemetry, publishes `src/Api` once to `bin/app-publish`, and deploys that one artifact with the web-app action. Infrastructure or login failure prevents application publishing. No SWA deployment token, Function key, or separate client deployment remains.

`webAppName` and `webAppDefaultHostname` come from subscription deployment outputs. For a known deployment name, inspect the URL with `az deployment sub show --name <deployment-name> --query properties.outputs.webAppDefaultHostname.value --output tsv`. CI names deployments `release-notes-<GitHub-run-id>`.

The API check step sets `RELEASE_NOTES_API_URL=https://<web-app-hostname>/api`, warms up the list route to initialize Cosmos, and mints a masked API-audience token. It separately obtains a masked ARM token only as an intentionally rejected wrong-audience fixture. Tests check public routes, rejection paths, compile/read-back/list/idempotency, and dependency health. The API token is scoped to the test process and never passed to the browser or written into artifacts. Live Chromium tests then verify the same web app origin.

Any failed API or browser assertion fails the workflow. On a new deployment, grant the web app's managed identity Azure DevOps access using the setup script before expecting the compile tests to pass. Do not interpret that prerequisite as permission to weaken tests or fall back to stubs. Deployment, cutover, and retirement remain separate operator decisions; see [Deployment](deployment.md).
